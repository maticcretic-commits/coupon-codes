# CouponCodes India 🇮🇳

Live site: **https://maticcretic-commits.github.io/coupon-codes/**

A single-page website listing hand-checked coupon codes and deals for India's biggest shopping, food-delivery and grocery services:

- 🛍️ **Flipkart** · **Myntra** · **Amazon India**
- 🍔 **Swiggy** · **Zomato** · **Domino's**
- 🛒 **Blinkit** · **Zepto**

**Features**
- Live search across stores, codes and offers
- Category filters: Fashion, Electronics, Food Delivery, Grocery
- One-tap copy buttons for every promo code
- Each card shows discount, terms, expiry and the public source page
- Dark-first, mobile-friendly design

**Honesty first**
- Offers were compiled from the public coupon pages of CouponDunia and GrabOn on **26 September 2026**.
- Codes change fast — always confirm the discount applies at checkout.
- Deals that need no code are labelled **"No code needed"**.
- This project carries **no affiliate links** and earns nothing from clicks.

CouponDunia's Flipkart, Swiggy and Zomato pages were geo-blocked at research time ("not available in your country"), so those stores' offers come from GrabOn's public pages.
